# SAGE Use Cases & Scenarios

## 1. Finding Lost Items
*   **Context:** A user misplaces their keys or wallet during the day.
*   **Retrieval:** The user asks SAGE: *"Where did I leave my keys?"*
*   **Result:** The AI scans the memory database, identifies the timestamp and location where keys were last seen, and displays a video link. Clicking the link plays the 15-second clip showing the user placing the keys on the kitchen counter.

---

## 2. Professional Meeting Recall
*   **Context:** A developer attends a standup and forgets specific action items discussed.
*   **Retrieval:** The developer queries SAGE: *"What tasks did we assign during the morning standup?"*
*   **Result:** The AI extracts the audio transcript of the meeting, summarizes the tasks, and lists them chronoly.

---

## 3. Personal Life Diary
*   **Context:** A user wants to review their week or build a daily journal.
*   **Retrieval:** The user browses the Memories Timeline.
*   **Result:** The timeline displays a visual summary of the week's events, complete with automatically generated titles (e.g., `Making_Coffee`, `Team_Meeting`) and categorized tags.
